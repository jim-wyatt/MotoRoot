# Guide kit version 1

Firmware-specific guide for the Walmart Straight Talk Moto G Power 2026 XT2617V, Android 16 build W1WEOS36.48-22-3-3-4-2 and April 1, 2026 patch.

Includes:

- Full guide and copyable Reddit introduction.
- Exact tested versions, checksums, failure notes, recovery limits, and post-root maintenance table.
- Reversible Motorola updater and 22-package carrier debloat module ZIPs.
- Carrier package manifest and module generator.
- Source and compiled DEX for staged-update reset and updater-alarm cleanup helpers.
- A guarded Magisk image preparation script that creates a file and never flashes a partition.

The phone procedure was verified on one unit. Bootloader flashing is experimental, can erase data, and can prevent Fastboot from starting. The repository does not provide a guaranteed unbrick method or claim compatibility with other firmware.

No firmware images, APK installers, device identifiers, account information, private backups, or unlock keys are included. Read GUIDE.md before using any file. Compare SHA256SUMS.txt after extracting the kit.
